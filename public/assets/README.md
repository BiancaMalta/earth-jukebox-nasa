# Visual asset credit

`orion-nebula.webp` is NASA's Hubble Space Telescope image of the Orion Nebula and is used as the page background.

- Image credit: NASA, ESA, M. Robberto (Space Telescope Science Institute/ESA), and the Hubble Space Telescope Orion Treasury Project Team
- NASA image page: https://science.nasa.gov/image-detail/orion-nebula-xlarge_web/
- ESA/Hubble archive entry for this mosaic: https://esahubble.org/images/heic0601a/
- Original file: https://science.nasa.gov/wp-content/uploads/2023/04/orion-nebula-xlarge_web-jpg.webp
- ESA/Hubble reuse terms: https://esahubble.org/copyright/

The ESA/Hubble archive publishes its images under CC BY 4.0 unless an image page says otherwise. The app footer displays the full image credit and links to NASA's source page.
